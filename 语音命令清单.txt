语音命令清单
================
热键: Super + Ctrl + V   (Super = Mac 键盘的 ⌘ Command 键)

按下后看到「🎤 语音控制」通知 → 6 秒内说话 → 等约 8 秒执行
识别引擎: whisper.cpp (本地)  指令解析: qwen3.8 (云端)

💡 亮度
  - 屏幕亮一点 / 亮一些 / 提高亮度
  - 屏幕暗一点 / 降低亮度
  - 亮度调到百分之五十
  - 键盘背光调亮 / 键盘背光调暗

🔊 音量
  - 音量加大 / 调小一点
  - 音量调到百分之八十
  - 静音 / 取消静音

🚀 打开应用
  - 打开浏览器        (Brave)
  - 打开文件管理器    (Thunar)
  - 打开终端 / 打开 htop / 打开 btop

🪟 窗口
  - 关闭当前窗口
  - 最小化窗口
  - 最大化窗口
  - 切换到下一个窗口

📸 截图
  - 截个图 / 截屏 / 全屏截图   (存到 ~/Pictures)

🎵 媒体
  - 播放 / 暂停
  - 下一首 / 上一首
  - 停止播放

😴 定时
  - 十分钟后息屏 / 半小时后关闭屏幕

🔍 搜索
  - 搜索今天的新闻
  - 谷歌搜索某某某

🗣 朗读
  - 朗读：今天天气不错     (会念出后面的文字)

✍️ 其他一切
  - 普通说话 → 自动打字到光标处 (nvim / 浏览器 / 终端均可)
  - 危险指令 (删除、格式化等) → 拒绝执行，只当普通文字

提示
  - 越接近上面的句式识别越准
  - 识别不出控制指令时会当普通文字打出来，不会误操作
  - 文字出现在你「按热键那一刻」所在的窗口
  - 每步都有桌面通知显示状态

相关文件
  - 脚本: ~/.local/bin/voice-ctl   (纯打字版: ~/.local/bin/voice-type)
  - 日志: ~/.cache/voice-type.log
  - 热键: ~/.config/sxhkd/sxhkdrc
